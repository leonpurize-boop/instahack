# InstahacK - Instagram Follower Tool

Ein JavaScript-basiertes Tool zum Hinzufügen von Instagram-Followern für **@cso0172** unter Verwendung der offiziellen Instagram API.

## Installation

```bash
npm install
```

## Konfiguration

1. Erstelle eine `.env` Datei mit deinen Instagram API-Credentials:

```
INSTAGRAM_ACCESS_TOKEN=your_access_token_here
INSTAGRAM_BUSINESS_ACCOUNT_ID=your_account_id_here
TARGET_USER=@cso0172
FOLLOWER_COUNT=50000
```

2. Hole dir einen Access Token von: https://developers.facebook.com/docs/instagram-api

## Verwendung

```bash
npm start
```

## Features

- ✅ Authentifizierung mit Instagram API
- ✅ Follower hinzufügen für Target-User
- ✅ Echtzeit-Logging
- ✅ Error Handling
